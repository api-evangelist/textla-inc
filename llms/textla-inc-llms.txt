# Textla Inc.

> Textla is a US business texting platform for bulk SMS/MMS marketing campaigns and two-way
> conversational messaging. It provides contact list segmentation, campaign scheduling and
> personalization, a shared team inbox, CSV contact import, and delivery/analytics reporting,
> with US-based human support. Textla operates on a bring-your-own-carrier (BYOC) model in
> which customers connect their own Twilio account and phone numbers.

**Textla publishes no public developer API.** As of 2026-08-13 there is no developer portal, no
API reference, no OpenAPI/AsyncAPI/GraphQL SDL, no SDK in any package registry, no CLI, no MCP
server and no A2A agent card. Programmatic integration is available only through Textla's
Zapier app. Do not attempt to construct API calls to Textla — any endpoint you find is an
undocumented internal backend for the app.textla.com web application and is not offered for
third-party use.
